Guide d'installation pas-à-pas

Sélectionnez votre appareil pour voir la méthode ultra-simple :

1
more_vert

Ouvrez le menu de Chrome

Appuyez sur les 3 petits points verticaux (⋮) en haut à droite de l'écran Chrome.

2
add_to_home_screen

Sélectionnez "Installer l'application"

Ou appuyez sur "Ajouter à l'écran d'accueil" dans la liste des options du menu.

3
check_circle

Confirmez l'installation

L'icône EasyArena ⚽ apparaîtra immédiatement sur votre écran d'accueil comme une application native !

info
Utilisez Safari uniquement

L'installation de PWA sur iPhone/iPad fonctionne uniquement avec Safari. Chrome et Firefox sur iOS ne supportent pas cette fonctionnalité.

1
public

Ouvrez ce site sur Safari

Assurez-vous d'utiliser le navigateur Safari officiel d'Apple (icône boussole bleue).

2
ios_share ↑

Appuyez sur le bouton Partager

Touchez l'icône Partager ios_share (carré avec flèche ↑) dans la barre du bas de Safari.

3
add_box

Choisissez "Sur l'écran d'accueil"

Faites défiler vers le bas dans la feuille de partage, puis touchez "Sur l'écran d'accueil" ⊞ et appuyez sur "Ajouter".

1
install_desktop

Repérez l'icône d'installation

Regardez tout à droite de votre barre d'adresse : une icône install_desktop (ordinateur avec flèche↓) devrait apparaître.

2
ads_click

Cliquez sur "Installer"

Validez la fenêtre pop-up pour installer la version bureau autonome d'EasyArena. Elle se lancera comme une vraie application !

3
rocket_launch

Profitez de l'application !

EasyArena se lancera maintenant dans sa propre fenêtre, sans navigateur — comme une application native.
